# STOCKPREDICT101

STOCKPREDICT101 is a stock-price prediction project focused on selected technology companies listed on the NASDAQ stock exchange.

The system uses more than five years of historical NASDAQ market data to analyze past price movements and generate stock predictions using an LSTM model.

## Supported Companies

The project includes the following companies:

- Alphabet
- Amazon
- AMD
- Apple
- Intel
- Meta
- Microsoft
- Netflix
- NVIDIA
- Tesla

## Technology Used

STOCKPREDICT101 uses **LSTM**, which stands for **Long Short-Term Memory**. LSTM is a type of **Recurrent Neural Network (RNN)** commonly used in deep learning.

LSTM models are particularly suitable for time-series data because they can learn patterns and dependencies from previous observations. In this project, the model uses historical stock-price data to identify trends and estimate future prices.

## How It Works

The general workflow of the system is:

1. Collect historical NASDAQ stock data covering more than five years.
2. Prepare and preprocess the data.
3. Train an LSTM-based deep-learning model.
4. Use historical price patterns to generate predictions.
5. Display or evaluate the predicted stock prices.
